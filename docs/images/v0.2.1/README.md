# 线上 0.2.1 截图记录

采集日期：2026-10-25（America/New_York）。来源：[线上产品](https://mingshai-production.up.railway.app/?v=0.2.1)。

本组图片通过浏览器实际点击、滚动和切换主题采集。桌面使用默认1280×720视口，手机使用390×844响应式视口；导出图片像素尺寸、采集时间、原始页面地址与SHA256见[capture.json](capture.json)。

线上当前采用规则解析。图片保留了模型状态、行情与估值的2026-10-23时点，以及上市日期沿用2026-10-15快照的来源提示。它们展示当前可操作的页面，不代表已经恢复真实模型调用。

| 文件 | 内容 |
|---|---|
| results.jpg | 主输入的结果分组、数据来源、逐条漏斗与条件影响 |
| understand.jpg | 口径确认、推荐默认项及尚未支持的口径 |
| conditions.jpg | 七项可编辑条件、行业包含与排除、字段覆盖率 |
| evidence.jpg | 上港集团样本的实际值、阈值、原始金额与请求编号 |
| results-dark.jpg | 相同条件与快照的夜间结果 |
| mobile-dark.jpg | 实际手机响应式视口下的夜间结果 |
| refusal.jpg | 对预测涨跌请求的拒绝与暂停执行状态 |

主输入为“经营改善、估值合理、走势相对稳定”；合规截图使用“明天会涨停的股票”。样本证据卡不代表推荐。

本组图片使用独立版本路径供README引用，避免旧图片缓存。旧版图片保留在上级目录。`scripts/readme_shots.py`可供后续自动重拍，本次实拍的来源以采集记录为准。
