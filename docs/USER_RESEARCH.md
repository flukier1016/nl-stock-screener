# 用户试用与访谈执行包

状态：待开展。没有真实参与者、访谈引语或测得的产品提升。

## 招募与方法

招募5–8位有基本PE、股息率知识、会定期整理观察池的个人投资者。记录经验范围与使用频率，覆盖不同熟练度；使用P01等匿名编号。任务使用固定快照或明确标注的合成数据，不需要提供真实账户、持仓或交易记录。

每人约30分钟：5分钟了解现有流程，15–20分钟完成任务，5分钟回顾。主持人允许参与者说出想法，但不提示按钮与条件答案。记录首次遇到阻碍的位置、原话和是否需要帮助。

与手工条件表比较时使用相同数据与期望条件，一半参与者先用自然语言，一半先用手工表。该小样本用于发现问题，不作为有统计显著性的A/B实验。

## 任务卡

1. 建立“经营改善、估值合理、走势相对稳定”的观察池。请用自己的话说明每个概念的实际定义，检查一只入选和一只未入选样本，并保存。
2. 在全部A股中排除银行，将股息率设为不低于3%。请确认剔除行业，解释为什么恰好3%的公司是否满足。
3. 输入“PE低于15倍或者股息率高于5%”。说明产品是否完整支持；如果不支持，尝试按提示拆成两次查询。不能把被阻止本身计为任务完成。
4. 输入“近20日波动率低于20%”，检查是否被换成其他期间。参与者明确改为受支持的60日后，才允许执行新任务。
5. 使用预先构造的缺失上市日期样本与快照更新失败场景，判断能否得出完整筛选结论、当前数据是哪一天。

任务1、2用于主流程时间比较。任务3–5用于边界理解与异常恢复；分别记录正确识别限制、成功改写和最终正确完成，不能合并为一个“成功”。

## 访谈提纲

- 最近一次建立或调整股票观察池是什么时候？当时如何找指标、确认口径、保存和复查？
- 哪一步最耗时？请描述具体的一次，而不是猜测理想需求。
- 刚才哪一个条件与你最初的意思不同？你是如何发现的？
- 哪些证据足够让你继续研究？哪些信息太多或仍然不足？
- 遇到无法理解或数据异常时，你认为产品执行了什么？下一步你会怎么做？
- 如果继续使用一周，你会重复哪项任务？是否愿意按约定回来复查一次？

避免先问“这个AI功能是不是很好用”，也不把口头喜欢当作留存证据。
