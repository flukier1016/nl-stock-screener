## 两分钟体验路线

1. 打开在线产品，点示例“经营改善、估值合理、走势相对稳定”，或者自己输入一句。
2. **第 2 步 确认理解**：每个模糊词都有 2～3 种口径，默认选推荐项；灰色虚线框是“想做但数据做不到”的口径及原因。换一个方案试试。
3. **第 3 步 检查条件**：这张表就是引擎实际执行的全部内容。改一个阈值、换一个基准（绝对值 / 行业中位数 / 全市场中位数），下方会实时提示冲突、口径不适用、张力和缺数据比例。
4. 点“运行筛选”。**第 4 步**：
   - 顶部是结果摘要、运行编号、数据快照与各类数据的时点；
   - 左栏“逐条漏斗”，右栏“条件变化的影响”：去掉每个条件会多出几只、多出谁；曲线上点一下，就把阈值改成那个值并重跑；
   - “入选 / 差一点 / 被排除 / 数据缺失”四个分组；**缺失不算通过**；
   - 点任一行打开证据卡：每个条件的实际值、阈值、差多少、计算展开、来源接口、字段、报告期、时点、request_id，底部分“事实 / 推断 / 不确定”三栏；
   - 搜索框可以查任意一只股票“为什么没入选”（包括没进股票池的原因）。
5. 勾选 2～5 只点“对比”；点“保存策略”或“转为监控”；“AI 白话解读”会展示它是否通过了数字守门器。
6. 试一句合规边界：“明天会涨停的股票”。

## 设计要点

- **AI 只翻译**：大模型只在口径字典里挑选概念、方案、指标、行业，输出受 JSON Schema 约束并逐片段过守门器；不输出股票和任何关于公司的数字。
- **引擎出结果**：筛选、计数、敏感度全部确定性计算；同一策略 + 同一快照 → 同一运行编号。
- **数字有出处**：每个值都能追到扶摇接口、字段、报告期、时点与 request_id。
- **不静默**：没有真实快照就不给结论；构建失败不替换旧快照；缺失单独成组；监控遇到同一快照明确写“没有新数据”。

## 题目要求逐条对照

| 题目要求 | 实现 | 页面位置 / 代码 |
|---|---|---|
| 自然语言意图的**澄清** | 每个模糊概念 2～3 个口径方案（推荐项 + 可选项），另列“做不到的口径”及原因（如“低于自身历史估值分位”：扶摇估值只有最新快照）；AI 复述理解、列出待确认问题 | 第 2 步 · `registry.py` `parse_llm.py` |
| **结构化条件** | `Strategy`（股票池 + 条件列表）纯 JSON，可序列化、可哈希、可保存 | 第 3 步 · `dsl.py` |
| **冲突识别** | 同一指标区间无交集（必然 0 只）、股票池互斥、口径不适用（负债率筛银行）、概念张力（用真实数据算“各自满足几只、同时满足几只”）、缺数据比例过高 | 第 3、4 步 · `conflicts.py` |
| **条件修改** | 表格内改指标 / 比较符 / 阈值 / 基准（绝对值、行业中位数、全市场中位数）；增删条件；在敏感度曲线上点选阈值；改动后旧结果标“已过期” | 第 3、4 步 |
| **AI / 引擎 / 数据工具职责边界** | 见 README“各角色的职责边界” | `parse_llm.py` / `engine.py` / `data/` |
| **入选 / 排除依据** | 证据卡逐条列实际值、阈值（相对阈值写明中位数和可比公司数）、差多少、计算展开（如 ROE 年化 = 原值 × 2） | 点任一行 · `explain.py` |
| **数据口径、时点、缺失** | 顶栏与结果头部写明估值快照时点、行情截止日、财务报告期；缺失单独成组，**不按通过处理** | 顶栏 / “数据缺失”分组 |
| **条件变化的影响** | 逐条漏斗；每个条件“去掉它多出几只 + 会多出谁”；阈值扫描曲线；结果太少时给出最近的放宽点 | 第 4 步右栏 |
| **比较、保存、回测或转监控** | 对比（2～5 只，含股票池分位）、保存策略、转为监控（快照更新后重跑，记录新进入 / 移出及原因）、导出 CSV；回测见“未做事项” | 第 4、5 步 · `monitors.py` |
| **合规边界** | 预测涨跌、收益承诺、买卖建议、目标价类表达在解析阶段拒绝并给出可验证的替代说法；整句只有这类内容时规则层直接拒绝、不调用大模型（合规前置）；AI 解读过合规检查；页脚声明 | `registry.REFUSE_PATTERNS` `parse_llm.parse` |
| **事实 / 推断 / 不确定区分** | 证据卡三栏分开 | 证据卡底部 |
| **数据缺失、冲突、过期、调用失败不得静默** | 没有真实快照时接口返回 503，页面不出任何结论；构建失败不替换旧快照；监控遇到同一快照明确写“没有新数据”；相对阈值样本不足记为缺失 | `store.py` `data/build.py` |
